# Screen prompt template

انسخ القالب واملأ الحقول بين الأقواس:

```text
صمّم شاشة [اسم الشاشة] لتطبيق [اسم/نوع التطبيق] بأسلوب Premium Adaptive Glassmorphism Mobile UI.

الهدف:
[ما الذي يريد المستخدم إنجازه؟]

المستخدمون والسياق:
[من يستخدم الشاشة؟ وعلى أي جهاز أو بيئة؟]

الميزات الحالية التي يجب الحفاظ عليها:
- [ميزة 1]
- [ميزة 2]
- [ميزة 3]

محتوى الشاشة:
- [عنصر أو قسم 1]
- [عنصر أو قسم 2]
- [عنصر أو قسم 3]

الترتيب البصري من الأعلى إلى الأسفل:
1. [Header أو عنوان]
2. [ملخص/بطاقة رئيسية]
3. [الإجراء الرئيسي]
4. [القائمة أو البيانات]
5. [التنقل]

الأسلوب البصري:
- بطاقات عائمة بحواف 20–32px
- Glassmorphism خفيف مع خلفيات مقروءة
- ظلال ناعمة وتدرجات هادئة
- أيقونات خطية موحّدة
- صور أو خلفيات ضبابية مرتبطة بالسياق مع طبقة تدرج للوضوح
- مساحات مريحة وشاشة غير مزدحمة
- خط [IBM Plex Sans Arabic / Tajawal / Cairo]
- دعم RTL كامل

الثيمات:
اجعل الألوان Semantic Design Tokens قابلة للتبديل، ولا تثبت الألوان داخل المكونات.
اعرض التوافق مع:
1. Pearl Light
2. Midnight Indigo
3. Aqua Breeze
4. Royal Violet

السلوك والتفاعل:
- الإجراء الرئيسي: [الوصف]
- الإجراءات الثانوية: [الأوصاف]
- عند التحميل: [السلوك]
- عند عدم وجود بيانات: [السلوك]
- عند الخطأ: [السلوك]
- عند انقطاع الاتصال: [السلوك]
- عند تبديل الثيم: معاينة مباشرة وانتقال لوني ناعم مع الحفاظ على نفس البنية.

الاستجابة:
- الهاتف: [الوصف]
- الجهاز اللوحي: [الوصف]
- سطح المكتب: [الوصف]
- RTL: اعكس التخطيط عند الحاجة، مع إبقاء الأيقونات غير الاتجاهية في مكانها المنطقي.

النتيجة المطلوبة:
قدّم مواصفة تنفيذية واضحة تشمل hierarchy، المكونات، المسافات، tokens، الحالات، وسلوك responsive، ثم اكتب Prompt نهائيًا جاهزًا لأداة التصميم أو التوليد.
```

## Example: electronics repair dashboard

```text
صمّم لوحة تحكم جوال لمركز صيانة إلكترونيات بأسلوب Premium Adaptive Glassmorphism Mobile UI.

حافظ على الميزات الحالية: استلام جهاز جديد، مسح باركود، المستودع، الطلبات، العملات، والتشغيل Offline-first.
اجعل الإجراء الرئيسي "استلام جهاز جديد" واضحًا، وأضف بطاقات للأجهزة المستلمة، قيد الصيانة، الجاهزة للتسليم، والمبالغ المستحقة، مع قسم آخر الطلبات والتخصصات.
استخدم RTL، IBM Plex Sans Arabic، بطاقات 24px، تباعد 8px، وثيمات Pearl Light وMidnight Indigo وAqua Breeze وRoyal Violet.
أضف حالات التحميل، الفراغ، الخطأ، عدم الاتصال، وتغيير الثيم مع الحفاظ على نفس بنية البيانات والوظائف.
```
