# صبر إلكترونكس

تطبيق جوال محلي لمحل صبر إلكترونكس لإدارة أجهزة الزبائن على Android وiPhone. يعتمد التطبيق على Expo SDK 54 وReact Native وTypeScript، ويحفظ البيانات والصور والإعدادات على الهاتف باستخدام AsyncStorage.

## الميزات المنفذة

- لوحة تحكم تعرض الأجهزة قيد المتابعة، الجاهزة للتسليم، المتأخرة والمدفوعات.
- إضافة جهاز جديد مع بيانات الزبون والهاتف والنوع والموديل والحالة والتواريخ والمبالغ والملاحظات.
- التقاط صورة بالكاميرا أو اختيار عدة صور من المعرض.
- دورة حالات كاملة: تم الاستلام، قيد الفحص، بانتظار موافقة الزبون، قيد الإصلاح، جاهز للتسليم، تم التسليم، لم يتم الإصلاح، وملغي.
- بحث بالاسم ورقم الهاتف ورقم الطلب ونوع الجهاز والموديل، مع تصفية حسب الحالة.
- تفاصيل الجهاز وتحديث الحالة وفتح WhatsApp برسالة جاهزة ومشاركة السجل وأرشفته.
- تقارير الحالات والمبالغ وأنواع الأجهزة، مع تصدير CSV المتوافق مع Excel وPDF.
- نسخ احتياطي واستعادة محلية بصيغة JSON.
- تنبيهات محلية للأجهزة الجاهزة للتسليم والمتأخرة.
- حماية اختيارية برمز PIN أو البصمة / Face ID.
- واجهة عربية RTL وهوية بصرية خاصة بالمحل.

## التشغيل المحلي

```bash
pnpm install
pnpm dev:metro
```

يمكن فتح المعاينة على الويب من خلال Expo، أو مسح QR الظاهر في Expo على جهاز Android/iPhone. لا يحتاج التطبيق إلى خادم أو حساب أو مفتاح API.

## بناء نسخة قابلة للتثبيت

بعد تثبيت EAS CLI وتسجيل الدخول إلى Expo، يمكن إنشاء نسخة Android أو iOS باستخدام:

```bash
npx eas build:configure
npx eas build --platform android
npx eas build --platform ios
```

يتطلب بناء iOS حساب Apple Developer، بينما يمكن اختبار Android عبر Expo Go أو development build. ميزات الكاميرا والبصمة والإشعارات والتصدير تعمل على الأجهزة الأصلية، وبعضها يحتاج development build بدل xpo Go.


## تحميل التطبيق

يمكن تحميل نسخة Android الجاهزة للتثبيت من رابط الـ Artifact الأخير في تبويب **Actions**. اختر Artifact باسم `sabr-electronics-release-apk`، ثم فك ضغطه وثبّت ملف `app-release.apk`. هذه نسخة Release مستقلة ولا تحتاج إلى تشغيل Metro أو توصيل الهاتف بالكمبيوتر.

لا تستخدم Artifact باسم `sabr-electronics-debug-apk`؛ فهو مخصص للتطوير ويحتاج إلى Metro.


## ملاحظات الخصوصية

هذه النسخة محلية أولًا كما اعتمدت الخطة. حذف التطبيق أو فقدان الهاتف قد يؤدي إلى فقدان البيانات ما لم يُنشئ المستخدم نسخة احتياطية. يوصى بإنشاء نسخة احتياطية دورية والاحتفاظ بها في مكان آمن.
