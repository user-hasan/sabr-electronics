# Settings Specification — مواصفات نظام الإعدادات

تم تنقيح واعتماد مواصفات الإعدادات بالكامل لتلائم طبيعة ورشة ومحل **صبر إلكترونكس** ونقاط البيع (POS).

يرجى مراجعة الدليل التنفيذي الكامل والمفصل في:
[universal_settings_ui_prompt.md](file:///e:/company's%20business/AI%20Studio/docs/universal_settings_ui_prompt.md)

## ملخص الأقسام الثمانية المعتمدة:
1. **بيانات المحل وترويسة الفاتورة:** الاسم، الهواتف، العنوان، الشعار، وشروط الضمان المطبوعة.
2. **العتاد والطباعة الحرارية:** البلوتوث/USB، مقاس 58mm مقابل 80mm، والطباعة التلقائية لسندات الاستلام والملصقات اللاصقة، وزر الطباعة التجريبية.
3. **المالية والعملات:** العملة الافتراضية والعملات المدعومة (ريال يمني YER، ريال سعودي SAR، دولار أمريكي USD)، وحد تنبيه قطع الغيار، وتفويض المدير عند الخصومات.
4. **الأمان والصلاحيات:** رمز PIN للمدير، مهلة القفل التلقائي، والبصمة.
5. **الوسائط والـ OCR:** مفتاح Gemini الآمن، حد الثقة، وجودة ضغط صور الأجهزة.
6. **المظهر والعرض:** الوضع الداكن والفاتح، والالتزام بـ RTL العربي.
7. **النسخ الاحتياطي والبيانات:** تصدير واسترجاع الأرشيف الشامل (قاعدة البيانات + الصور).
8. **منظومة التحديث وترقية النظام (In-App Update):** فحص التحديثات، سجل التغييرات، التحميل والتثبيت المباشر، مع ضمانة عدم فقدان البيانات (نسخ طارئ آلي وهجرة SQLite تراكمية آمنة).
