# Security & Privacy — الأمان والخصوصية وحماية البيانات

## 1. حماية مفاتيح الـ API السحابية
- يُمنع منعاً باتاً تضمين مفتاح Gemini API Key داخل الكود المصدري أو ملفات Git المرفوعة.
- في بيئة التطوير والاختبار: استخدام متغيرات البيئة عبر `--dart-define` أو ملف `.env` مدرج في `.gitignore`.
- في بيئة الإنتاج: حفظ المفتاح مشفراً عبر `flutter_secure_storage` أو الاستدعاء عبر وسيط آمن (Secure Backend Proxy).

---

## 2. الصلاحيات وحماية العمليات الحساسة (RBAC & PIN Protection)
يتم تصنيف المستخدمين إلى ثلاثة مستويات تحمي استقرار وأموال المحل:

| العملية | فني صيانة (Technician) | كاونتر / استقبال (Reception) | صاحب المحل / مدير (Owner/Admin) |
| :--- | :---: | :---: | :---: |
| استلام جهاز وتسجيل عميل | نعم | نعم | نعم |
| تحديث الحالة الفنية والملاحظات | نعم | نعم | نعم |
| قبض عربون أو دفعة مالية | لا | نعم | نعم |
| إضافة قطع غيار وخدمات | نعم | نعم | نعم |
| تعديل سعر أو منح خصم إضافي | لا (يتطلب PIN مدير) | لا (يتطلب PIN مدير) | نعم |
| حذف سجل صيانة أو عميل | ❌ ممنوع | ❌ ممنوع | نعم (مع تأكيد) |
| الاطلاع على أرباح المحل وتقاريره | ❌ ممنوع | ❌ ممنوع | نعم |
| استعادة نسخة احتياطية | ❌ ممنوع | ❌ ممنوع | نعم (مع إدخال PIN) |

---

## 3. سجل الرقابة والتدقيق (Audit Trail)
- أي تعديل على الأسعار أو خصم مالي يُسجل فوراً في جدول `audit_logs` مع:
  - معرف المستخدم (`userId`).
  - القيمة السابقة والجديدة.
  - التاريخ والوقت بالثانية.
- يُمنع حذف أي سجل من جدول `audit_logs` حتى من صاحب المحل.

---

## 4. حماية خصوصية العملاء وصور الأجهزة
- **عزل وسائط الأجهزة:** تُحفظ صور الأجهزة والوثائق في المجلد الداخلي الخاص بالتطبيق (Internal App Sandboxed Storage)، وتُمنع من الظهور التلقائي في معرض الصور العام للهاتف (Public Gallery).
- **تقليل البيانات المرسلة للسحابة (Data Minimization):** لا يتم إرسال أي صورة تحتوي على وجوه العملاء أو مستندات هوية كاملة إلى Gemini، بل يتم اقتصاص الجزء المحتوي على النص المطلوب قراءته فقط.

---

## 5. النسخ الاحتياطي والأمان ضد فقدان البيانات (Backup & Recovery)
- توفير نسخ احتياطي تلقائي يومي أو أسبوعي يحفظ:
  1. ملف قاعدة البيانات `sabr_electronics.db`.
  2. أرشيف الصور المضغوطة.
- إمكانية التصدير إلى وحدة تخزين خارجية أو فلاش ميموري (USB OTG) أو Google Drive.
- عند استرجاع نسخة احتياطية:
  - يُلزم النظام بإدخال PIN المدير العام.
  - يظهر تحذير أحمر واضح بأن الاستعادة ستستبدل البيانات الحالية.
  - يتم أخذ نسخة احتياطية تلقائية طارئة من الحالة الحالية قبل كتابة النسخة المسترجعة.
