# Master Requirements Checklist — قائمة متطلبات النظام الشاملة

## 1. إدارة العملاء (Customers)
- [ ] إضافة عميل جديد
- [ ] تعديل بيانات العميل
- [ ] البحث الفوري بالاسم أو رقم الهاتف
- [ ] دعم الهاتف الأساسي والهاتف البديل
- [ ] سجل الأجهزة السابقة لكل عميل

## 2. إدارة وتوصيف الأجهزة (Devices)
- [ ] تحديد تصنيف التخصص: (أجهزة طبية، شاشات سيارات، مضخمات، صوتيات، إلكترونيات وباور)
- [ ] الشركة الصانعة والموديل ورقم البوردة أو الشاسيه
- [ ] بيانات السيارة (نوع وموديل وسنة السيارة لشاشات ومسجلات السيارات)
- [ ] بيانات الجهة والعيادة/المستشفى (للأجهزة الطبية)
- [ ] فولتية وتيار التشغيل (12V, 24V, 220V, Power Wattage)
- [ ] الملحقات المستلمة (فيش توصيل، ضفائر أسلاك، محولات، كابلات، ريموت)
- [ ] توصيف الحالة الفيزيائية ومناطق الاحتراق والكسور الظاهرة

## 3. معالجة وتوثيق الصور (Image System)
- [ ] التقاط صور بالكاميرا أو المعرض
- [ ] معالجة رقمية حتمية (اقتصاص، تدوير، تصحيح إضاءة وتباين)
- [ ] حظر الذكاء الاصطناعي التوليدي من تعديل صور الأجهزة
- [ ] ضغط تلقائي للصور (1-2MB كحد أقصى)
- [ ] توليد صور مصغرة (Thumbnails) لتسريع العرض
- [ ] تخزين الصور داخل مجلد التطبيق الخاص والمحمي (Sandbox)
- [ ] ختم البصمة الزمنية ورقم السجل على الصورة

## 4. مستودع قطع الغيار والخدمات (Spare Parts & Services)
- [ ] دليل قطع الغيار مع الكود أو الباركود
- [ ] تسجيل سعر التكلفة وسعر البيع
- [ ] تتبع كمية المخزون وتنبيهات قرب النفاد
- [ ] خصم آلي للكميات عند استخدامها في عمليات الصيانة
- [ ] تسجيل خدمات الصيانة (أجور اليد)

## 5. دورة الصيانة (Repair Workflow)
- [ ] معالج استلام جهاز جديد (Intake Wizard) سريع
- [ ] تتبع الحالات: (تم الاستلام، قيد الفحص، بانتظار الموافقة، قيد الإصلاح، بانتظار قطع غيار، جاهز للتسليم، تم التسليم، تعذر الإصلاح)
- [ ] تسجيل تقرير الفحص الفني والملاحظات الداخلية
- [ ] سجل تتبع تاريخ تغيير الحالات ومن قام بالتغيير (`repair_status_history`)
- [ ] تحديد فترة الضمان الممنوحة على الإصلاح (بالأيام)

## 6. الإدارة المالية والمحاسبية (Financials & Payments)
- [ ] معادلة التكلفة الآلية: (أجور اليد + قطع الغيار - الخصم = الإجمالي)
- [ ] تسجيل التكلفة التقديرية المتفق عليها أولياً
- [ ] تسجيل العربون والدفعات المجزأة مع أرقام السندات
- [ ] احتساب المبلغ المتبقي بدقة وتحديثه آلياً ضمن SQLite Transactions
- [ ] دعم طرق الدفع المتعددة (نقداً، الكريمي، جوالي، تحويل بنكي)
- [ ] ضبط العملات المدعومة (ريال يمني YER، ريال سعودي SAR، دولار أمريكي USD مع تحديد العملة لكل سند ودفعة)

## 7. الطباعة الحرارية والباركود (Thermal Printing & Barcode)
- [ ] دعم بروتوكول ESC/POS عبر البلوتوث وUSB
- [ ] دعم مقاسي الورق 58mm و 80mm
- [ ] معالجة النصوص العربية النقطية بدقة (Arabic Text Shaping) دون تقطيع للحروف
- [ ] طباعة سند استلام فوري للعميل مع رمز QR وشروط الصيانة
- [ ] طباعة ملصق الباركود الصغير اللاصق على ظهر الجهاز
- [ ] طباعة فاتورة التسليم وسند القبض النهائي مع تفاصيل الضمان
- [ ] ماسح باركود/QR عبر الكاميرا للوصول الفوري لسجل الجهاز

## 8. الذكاء الاصطناعي الهجين (Hybrid AI)
- [ ] Google ML Kit محلي لقراءة كروت الضمان وأرقام الهواتف والسيريال أوفلاين
- [ ] شاشة مراجعة وتحقق بشري إجبارية قبل حفظ مخرجات الـ OCR
- [ ] مسار سحابي اختياري عبر Gemini للخطوط اليدوية عند توفر الإنترنت
- [ ] مساعد تحليلي لتلخيص مؤشرات الأداء والأرباح الدورية
- [ ] مستشار فني لاقتراح خطوات تشخيص الأعطال المعقدة
- [ ] توليد قوالب رسائل واتساب جاهزة لإشعار العملاء بجاهزية أجهزتهم
- [ ] حظر Gemini التام من الكتابة المباشرة في قاعدة البيانات

## 9. الأمان والصلاحيات (Security & RBAC)
- [ ] نظام صلاحيات ثلاثي (مالك، كاونتر، فني)
- [ ] قفل سريع برمز PIN للتبديل بين المستخدمين وحماية الشاشات
- [ ] حماية العمليات الحساسة (الخصومات، الحذف، التقارير) برمز PIN المدير
- [ ] تفعيل سجل الرقابة والتتبع غير القابل للحذف (`audit_logs`)
- [ ] حظر كتابة مفاتيح الـ API في الكود أو Git

## 10. النسخ الاحتياطي (Backup & Recovery)
- [ ] تصدير نسخة احتياطية شاملة (ملف SQLite + أرشيف الصور) محلياً أو إلى USB
- [ ] استعادة النسخة الاحتياطية بأمان مع التحقق من PIN المدير وأخذ نسخة طارئة قبل الاستبدال
- [ ] إظهار تاريخ وحجم آخر نسخة احتياطية

## 11. واجهة وتجربة المستخدم (UI & UX)
- [ ] دعم اللغة العربية واتجاه RTL بنسبة 100%
- [ ] تصميم عالي التباين وثيمين متكاملين (Dark & Light)
- [ ] شريط بحث محلي فوري فائق السرعة (< 50ms)
- [ ] مؤشرات لوحة التحكم اللحظية (KPIs)
- [ ] حالات التحميل، الأخطاء، والقوائم الفارغة (Empty States)

## 12. معايير الجودة والاستقرار (Testing & Stability)
- [ ] اختبارات دقة الحسابات المالية ومنع المبالغ السالبة
- [ ] اختبار استمرارية العمل 100% في وضع الطيران (Offline-First)
- [ ] اختبار كفاءة الذاكرة مع الصور وضمان عدم تضخم التخزين
- [ ] اختبار سلامة القيود والعلاقات في قاعدة البيانات (Foreign Keys & Transactions)
